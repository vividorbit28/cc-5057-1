# 轨道站拼装台 · 关卡模块生成器

用自制走廊、设备舱与连接件，按**接口类型 / 朝向 / 边界尺寸**拼装可实际进入的三维轨道站场景。
求解器带可复现种子与失败解释；界面可逐步观察选择与回退，并保存生成清单。

## 启动界面

```bash
node ui/server.js          # 默认 8080 端口
# 打开浏览器访问 http://localhost:8080/ui/
```

零依赖、纯 ES 模块，无需 npm install、无需构建。

## 命令行与测试

```bash
node kernel/cli.js --preset medium --seed demo-1   # 生成并输出清单到 out/
node kernel/cli.js --preset list                   # 列出预设
node --test 'tests/*.test.js'                      # 全部测试（27 个）
```

## 玩法（界面）

- **生成关卡**：选预设与种子 →「生成关卡」→ 用 ⏮ ◀ ▶ ⏭ / 自动播放逐步观察求解器的
  放置、局部改向（牺牲该朝向出口）、全局回退（牺牲先前置件出口）、闭环提交/放弃决策。
- **手动拼装**：从模块托盘拖入视窗，Q/E 旋转；内核实时判定，非法放置会被拒绝并说明理由
  （重叠 / 门洞被墙堵死 / 接口类型或朝向不匹配 / 间距不足 / 越界）。
- **结果区**：点击开放端（绿色门框）→ 列出内核计算的**可行连接**，点击直接落位。
- **验收**：对当前装配件做几何碰撞 + 导航通路检查，乘客路线以红线画在场景中。
- **保存生成清单**：导出 JSON（种子、规格、放置、连接、开放端、验收报告、内核反馈）。

## 内核约束（`kernel/`）

| 约束 | 实现 |
|---|---|
| 接口匹配 | 类型一致（C2/C4）+ 朝向相对 + 门洞边界重合；不匹配即拒绝，不做视觉遮挡 |
| 不重叠 | 模块包围盒严格相交检测（贴面合法） |
| 门洞不被堵 | 门洞外探盒碰到邻模块时，邻模块必须有对齐接口，否则拒绝 |
| 区域间距 | 指定标签舱室的 AABB 最小间距（如 反应堆↔医疗舱 ≥ 8m） |
| 入口→目标舱连通 | 装配几何上 0.5m 导航网格 BFS，绕过舱内设备障碍 |
| 闭环提交 | 最后一接口落位成环时，以乘客可达路线 + 出口账面决定是否提交 |
| 可复现 | 同一种子 → 同一份清单（字节级一致） |
| 失败解释 | 返回冲突模块与条件；搜索有节点预算，不无限重试 |

## 验收口径

`validateScene` 从**实际装配结果**重建碰撞体（墙体在门洞处真实开洞）与可通行表面，
做几何碰撞、接口审计、间距复验与导航通路检查；篡改场景（移动模块）必然验收失败。

## 目录

```
kernel/    拼装内核：geom / modules / assembly / solver / validate / exhaustive / generator
ui/        关卡编辑视窗：viewport(软件3D) / editor(拖放) / main(生成与回放) / server
tests/     node --test 测试：几何、模块、求解、穷举核对、验收、界面冒烟
out/       示例生成清单
```
